# v1.0.0

First public release. Decodes analogue FPV video straight out of HackRF IQ,
sweeps the 5.8 GHz band for energy above the noise floor, names what it finds on
the VTX band chart, and alerts with **band + channel + frequency**.

## Download

**`FPV-RF-v1.0.0-windows-x64.zip`** — 87 MB, 303 files, 212 MB extracted.

1. Verify the download if you want to:
   ```
   sha256sum -c FPV-RF-v1.0.0-windows-x64.zip.sha256
   ```
   or in PowerShell:
   ```
   (Get-FileHash .\FPV-RF-v1.0.0-windows-x64.zip -Algorithm SHA256).Hash
   ```
2. Extract it. Everything lands in one `FPV-RF\` folder.
3. Double-click **`FPV-RF.exe`**.

That is the whole procedure. No Python, no pip, no drivers. `hackrf_transfer.exe`
is already in the folder beside the app, and the app looks there *before* `PATH`,
so the copy that ships is the one that runs.

**Windows will warn you the first time.** The app is unsigned, so SmartScreen
says it published an app from an unknown source. Click *More info* → *Run anyway*.
The warning is about the missing signature, not about this program.

Expect the first launch to take around fifteen seconds. Windows Defender scans
every one of the 300-odd freshly-extracted files, and it does that before the
window appears. The second launch is about a second.

## What it needs

A HackRF One plugged into USB. No FPV gear has to be transmitting — the app is
useful precisely when nothing is, and the simulator needs nothing at all.

The app opens on the HackRF by default, because a double-clicked program should
use the radio plugged into it rather than showing a convincing fake picture.

## Verifying it works

With nothing transmitting, the window should find **no** carrier on a quiet
band. That absence is the point: it is what proves the alert is not firing on
the radio's own local-oscillator leakage, which sits 52 dB above the noise floor
right at the centre of every tuned frequency. A build that alerts on an empty
band is broken.

To see it work end to end without hardware, run it from source with
`python main.py`, which uses the built-in simulator.

## Notes on what is not in this release

- The **occupied** case is untested. Every piece of hardware evidence so far
  concerns a finding correctly *not* appearing, because no drone was
  transmitting during development. The first run with a VTX in the air is
  documented in the README under *The optional real capture*.
- There is no in-app version string. The release tag is the version.
- Unsigned. See above.
